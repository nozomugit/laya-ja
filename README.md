# Laya-JA

日本語の文章を読み、選択肢、二値確率、0〜5の評点を返すための、用途別の学習済みアダプターです。Convai Innovations の Laya Multilingual（322M）をベースに、日本語で書かれた JGLUE と JCoLA を使って追加学習しました。各選択肢の特徴を計算する部分を固定し、各候補の最終スコアを計算する768個の重みを学習しました。その上に幅16または48の小型ニューラルネットを加える方式も比較し、課題ごとに公開する構成を選びました。四つの用途で、それぞれ異なる重みを読み込みます。独立したコミュニティプロジェクトです。

## 公式開発セットでの実測結果

| 公式開発セットと指標 | 件数 | 上流の多言語版 | Laya-JA |
|---|---:|---:|---:|
| JNLI・推論 正答率 | 2,434 | 52.2% | 72.1% |
| JCommonsenseQA・常識五択 正答率 | 1,119 | 54.6% | 54.7% |
| JSTS・意味類似度 Pearson相関 | 1,457 | 0.601 | 0.684 |
| JSTS・意味類似度 平均絶対誤差（小さいほどよい） | 1,457 | 0.949 | 0.863 |
| JCoLA・文法判断 同分野 MCC | 865 | -0.005 | -0.002 |
| JCoLA・文法判断 異分野 MCC | 685 | 0.005 | 0.021 |

JNLI の差は +19.9 ポイント（95%区間 +17.4 〜 +22.7）。JCommonsenseQA の差は +0.1 ポイント（95%区間 -0.5 〜 +0.7）。

JNLI のラベル別再現率は、判断できない 28.6% → 77.0%、含意 75.1% → 48.4%、矛盾 84.8% → 74.3%。独自36問では 14 → 12 問正解でした。写真の説明文を中心にした JNLI と、条件や伝聞を読み分ける診断とでは、結果の方向が異なりました。

JCommonsenseQA で正解した問題は 611 → 612 問とほぼ横ばいでした。予測確率と実際の正答率のずれを表す ECE（10区間、低いほどよい）は 0.119 → 0.031 でした。

順序を逆転させても同じ意味の候補を選んだ割合は、JNLI で 93.6% → 93.0%、JCommonsenseQA で 74.0% → 73.8%（各512問）。

JCoLA は実験用です。同分野の開発セットでは多数クラスだけを選ぶと正答率 83.9% になります。公開版の正答率は 71.1%、MCC は -0.002 でした。両クラスを識別できるという実証は得られていません。線形層だけの結果を確認した後に、クラス重みを加えた追加比較を行いました。報告値は公式の開発セット上の探索的な評価です。

学習用の例は合計12,288件、候補比較用は768件、公式開発セットは合計6,560件です。単一シードです。モデル選定は各課題の調整用192件で行いました。各段階の結果、確率の評価、追加診断の各問の判定は [results](results/) に収録しています。

## 試す

Python 3.12 と CPU で実行できます。初回は Hugging Face から約644 MBの重みとトークナイザーを取得します。公開モデルの利用に API キーは不要です。

```bash
git clone https://github.com/nozomugit/laya-ja.git
cd laya-ja
python3.12 -m venv .venv
source .venv/bin/activate
python install.py
python predict.py jnli '整理券の所持者は全員入場できる。秋さんは持っていない。' '秋さんは入場できる。'
python predict.py jcommonsenseqa '鉛筆で書いた線を消すために使うものは？' '定規' '消しゴム' '封筒' '電卓' '切手'
python predict.py jcola '机の上に本がある。'
python predict.py jsts '男性が犬の散歩をしている。' '男性が犬を連れて歩いている。'
```

最初の例の正解は「判断できない」です。整理券を持つ人についての条件だけでは、持たない人が入れるかどうかは決まりません。公開した推論版は、この例を「矛盾」（約0.75）と誤判定しました。コマンドで実際の判定と確率を確かめられます。Windows では仮想環境を `.venv\Scripts\activate` で有効にできます。

| 読み込む重み | Laya 出力型 | 学習した判断 |
|---|---|---|
| `jnli` | choice | 前提から仮説が言える、矛盾する、判断できない |
| `jcommonsenseqa` | choice | 日本語の常識問題に五択で答える |
| `jcola` | noul | 文が JCoLA の容認可能性ラベル「1」と判定される確率 |
| `jsts` | score | 文の対の意味の近さを0〜5の期待値で返す |

Python からは `from laya_ja import load, query, nli_request`、続いて `agent = load("jnli")`、`query(agent, *nli_request(前提, 仮説))` で利用できます。内部では上流の `Agent.predict` が動きます。今回検証した出力は選択結果、二値確率、意味類似度の評点です。付随する action フィールドの再学習・評価は行っていません。用途に対応した質問文と尺度は `laya_ja.py` に収録しています。ローカルのベースモデルを使う場合は `python predict.py --model-path /path/to/base jnli ...` を使います。

## 学習と評価の再現

```bash
python experiment.py     # JNLI と JCommonsenseQA の線形層と評価用特徴を作成
python compare_heads.py  # その特徴から追加の非線形層を学習・比較
python typed.py          # JCoLA と JSTS の両段階を学習・比較
```

データは各配布元の固定コミットから取得し、SHA-256 を照合します。選択問題は各4,096件、二値判断と段階評価は各2,048件で最終重みを学習します。各課題にさらに192件の調整用データを確保し、公式の開発セット全件を最終評価に使います。データ抽出の乱数シードは42。ベースモデルが過去の学習で各データに触れたかどうかは未確認です。

選択問題の学習データのうち3,072件は、選択肢の順序と正解位置を一緒に入れ替えています。評価問題のうち各512件は、すべての選択肢を逆順にして再評価します。日本語推論には、否定の範囲、助詞、伝聞、数量、条件、時点などを変えた独自の36問もあります。これは三つの正解を均等に用意した小規模な追加診断です。

ベースモデルの表現を固定し、各選択肢の特徴を取り出して、最終スコア層の重みを交差エントロピーで最適化します。JSTS の小数評点は隣り合う整数に線形配分します。元の重みからの変化に対する正則化強度5通りと無変更のベースラインを比較し、独立した調整用データで候補を選びます。選択問題と二値判断では負の対数尤度、JSTS では平均絶対誤差を使います。続いて幅16と48の残差ネットを学習し、4・12・24エポック時点を比較しました。二値文法タスクはラベル件数の逆数による重みを用い、この段階ではクラスの偏りに配慮して調整用データの MCC（マシューズ相関係数）で選びました。各課題の「-final.json」が公開アダプターの成績です。選択問題の正答率差には、同一問題の学習前後を対応づけたブートストラップ区間を付けています。JNLI は画像IDまたは画像IDの組を単位に再標本化しました。

評価時は CPU の float32 演算を用います。並列度、ライブラリのバージョン、ハードウェアが異なる場合は、小数点以下や境界上の判定に差が出ることがあります。セットアップでは、実験に使った Laya の PyTorch テキストエンジンを固定します。別エンジンの Vega が要求する Transformers とはバージョンが異なるため、テキストエンジンの依存関係を個別に導入します。
