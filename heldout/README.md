# 独自評価問題（公開用）

`dev.jsonl` は、Laya-JA の学習に使っていない問題で実力を測るための公開用200問です。推論の三択144問（24分野×6問）、実務文書を読んで答える選択24問・二値16問・評点16問からなります。

- **問題文と正答はAIが作成した草案です。** 正答は人による検証をまだ受けていません。
- 学習には使いません。誤答の分析と、学習データの設計の参考に使います。
- 正式な成績は、別に管理する封印用800問で測ります。封印用の問題文はこのリポジトリに置きません。

各行が1問です。`type` は `nli`（正答は 含意・矛盾・判断できない）、`choice`（1始まりの選択肢番号）、`noul`（真偽値）、`score`（0〜5）。モデルに渡すのは `state`、`question`、必要な場合の `options` だけです。

```bash
python heldout_eval.py --checkpoint path/to/unified --upstream --out results/heldout-dev.json
```
